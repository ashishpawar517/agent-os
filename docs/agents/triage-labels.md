# Triage labels

These are the default triage labels used by the `triage` skill.

- `needs-triage`: Default state for new issues
- `needs-info`: Waiting for more information from the issue author
- `ready-for-agent`: Issue is clear and ready for an agent to work on
- `ready-for-human`: Issue is clear and ready for a human to work on
- `wontfix`: Issue will not be addressed

The triage skill moves issues through these states based on agent and human input.
